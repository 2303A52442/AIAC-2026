# AIAC Project

This folder contains a small standalone project structure inside the repository.

Files:
- `app.py` - minimal Flask backend
- `index.html` - simple frontend page
- `README.md` - setup notes

## Run

1. Install Flask:

```bash
pip install flask
```

2. Start the app:

```bash
python app.py
```

3. Open the local URL shown in the terminal.
