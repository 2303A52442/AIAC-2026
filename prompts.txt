I need you to build me a complete web application called "MedOrigin AI" that can verify whether pharmaceutical tablets and capsules are genuine and identify where they were manufactured just by analyzing their images. The app should work end-to-end with both a backend service and a user-friendly interface.

For the backend, I'm going to need you to:
- Create an image preprocessing pipeline that cleans up the tablet photos using Gaussian Blur to remove noise and CLAHE to enhance the contrast so we can see the fine details better
- Build a CNN model using TensorFlow or Keras with multiple convolutional layers at different scales (like 3x3 and 5x5 kernels) so it can capture both large and small texture features
- Convert what the model extracts into a 256-dimensional vector and normalize it so we can compare different tablets fairly
- Set up a matching system that compares the tablet's vector against a database of known genuine tablets using cosine similarity and Euclidean distance metrics
- Implement a classification system that tells us if a tablet is genuine (score above 0.90), suspicious (between 0.60-0.89), or counterfeit (below 0.60)
- Create a Flask API with a /verify endpoint that accepts uploaded images and returns the authenticity status, confidence percentage, manufacturing source, and similarity score as JSON
- Organize the code into clear modules like PreProcessing.py, Model.py, Classification_model.py, and Main.py

For the frontend, please create a user-friendly interface using either React or HTML/CSS/JavaScript that:
- Lets users drag and drop tablet images or click to upload them
- Shows a preview of the image they uploaded
- Has a "Verify" button that sends it to the backend for analysis
- Displays the results in a nice format showing whether the tablet is genuine, suspicious, or counterfeit with a confidence score and the manufacturing source identified
- Uses visual cues like green for genuine, yellow for suspicious, and red for counterfeit tablets
- Has a modern, clean design with a healthcare/AI theme using blue and green colors, presented in a dashboard-style result card

Make sure everything integrates smoothly together!
